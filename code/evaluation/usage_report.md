## Where models are used

- **Intent** (`gpt-4o-mini`): does the request text authorize deletion? Falls back to a deterministic multilingual regex without a key.
- **Vision** (`gpt-4o`): read the records shown in PDFs and screenshots (resource id or printed reference, identifiers, explicit state). Results are plausibility-checked (and, for PDFs, must appear verbatim in the text).
- Everything else — identity resolution, discovery, policy, status, remediation ordering — is deterministic code; no model decides a status.
